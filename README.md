# Gløgg Crawl Kopenhaga

Karty na piątkowy obchód jarmarków świątecznych w Kopenhadze (27.11). Każdy przystanek to fiszka: z przodu adres z pinezką w Google Maps i dojście, z tyłu duńska rzecz do zrobienia wszyscy, wyzwanie z karą i bonus. Tabela punktów, każdy gra na siebie, a przegrany wyścigu na łyżwach nosi czerwone rogi renifera.

Działa na telefonie jako aplikacja (dodaj do ekranu początkowego) i bez internetu.

## Zmiana treści

Cała treść kart jest w `src/data/cards.ts`. Po zmianie i wypchnięciu na `main` GitHub sam zbuduje i opublikuje nową wersję.

## Uruchomienie na komputerze

```powershell
npm install
npm run dev
```

Sprawdzenie przed wypchnięciem (typy, lint, testy):

```powershell
npm run check
```
